# Chanderi Quest — Godot

Godot-native 2D top-down RPG.

- Godot 4.x
- 384x216 logical viewport
- 16px pixel-art grid
- Female protagonist: Asha
- Chanderi Village vertical slice
- Four-direction movement
- NPC interaction and dialogue
- First quest: The Missing Package
- Native Save/Load through user://
- Android export preset

This folder is intentionally isolated from the older Aether Resonance / Pixel Quest implementation.
